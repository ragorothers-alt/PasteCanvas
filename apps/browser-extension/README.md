# PasteCanvas Browser Extension

A Manifest V3 extension that captures web content into PasteCanvas via Chrome/Edge
**Native Messaging**. Fully local — no cloud services, per PRD CAP-008.

## What it captures (right-click context menu)

| Menu item | Captures |
|---|---|
| Save page to PasteCanvas | The current page URL + title |
| Save selection to PasteCanvas | Selected text + source URL |
| Save link to PasteCanvas | A link's `href` |
| Save image to PasteCanvas | An image's `src` URL |
| Save video link to PasteCanvas | A video/audio `src` URL |

## How it works

1. The extension's background service worker (`background.js`) creates the context
   menu items and forwards clicks to the **Native Messaging Host**.
2. The host is the `pastecanvas-nmh` binary, which speaks the length-prefixed JSON
   Native Messaging protocol over stdin/stdout.
3. The host writes the capture into the same SQLite database the desktop app uses
   (`%APPDATA%\com.pastecanvas.desktop\pastecanvas.sqlite3`). Nothing leaves the machine.

## Installation

1. **Build the desktop app + NMH.** The `pastecanvas-nmh.exe` binary must sit next to
   the main app executable (produced by the Cargo workspace build).
2. **Load the extension** in Chrome/Edge:
   - Open `chrome://extensions` (or `edge://extensions`).
   - Enable **Developer mode** → **Load unpacked** → select this folder.
3. **Copy the extension origin** shown on the extension card, e.g.
   `chrome-extension://abcdefghijklmnopqrstuvwxyz123456/`.
4. **Register the host**: in the PasteCanvas desktop app, open **Settings → Browser
   Extension**, paste the origin, and click **Register**. This writes the native
   messaging manifest and registers it for Chrome and Edge.
5. Right-click any page/selection/link and choose a **Save … to PasteCanvas** action.

## Files

- `manifest.json` — MV3 manifest (`contextMenus` + `nativeMessaging` permissions only).
- `background.js` — service worker; context menus + native messaging.
- `icons/` — extension icons (generated by `generate-icons.cjs`).
- `generate-icons.cjs` — regenerates the PNG icons (Node built-ins only).

## Privacy

- Permissions are minimal: `contextMenus` and `nativeMessaging`. No host permissions,
  no remote code, no analytics, no network calls from the extension itself.
- All captured data is stored locally by the desktop app's database.
